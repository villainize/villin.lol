# bf-db image folders

Put your Brave Frontier images in these folders and keep the matching paths in `bf-db/data/catalog.js`.

## Folder map

- `units/img/` - all unit images together: full art, thumbnails, and battle images. Examples: `unit_ills_full_10011.png`, `unit_ills_thum_10011.png`, `unit_ills_battle_10011.png`
- `items/item/` - item icons and sphere icons together. Examples: `item_700001.png`, `sphere_818000.png`
- `icons/` - element icons, rarity icons, UI badges
- `backgrounds/` - banners and page backgrounds

The starter data already points at this flat layout. If your filenames are different, only update the image paths in `data/catalog.js`.
